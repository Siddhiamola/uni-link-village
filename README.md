# Campus Hub

Build a unified, responsive college super-app called "CampusOS" with a clean, modern dark mode (Tailwind CSS, sleek dark slate backgrounds, vibrant blue and emerald accents).

Layout Requirements:

Left Sidebar Navigation with working tab switching for:

🧑‍💻 Who Can Help? (Collab Finder)

🚌 Smart Transport

🏢 Hostel Hub

📚 Senior Bridge

🔄 Resource Sharing

🗺️ Campus Map & Cleanliness

📊 Academic Risk Detector

Main Content Area:

Default view should be "Who Can Help?". Build it completely right now:

A large natural search bar at the top: "e.g. Need someone who knows Arduino for SIH".

Quick filter tags: "All", "SIH", "Arduino", "Web Dev", "Robotics", "ML".

A grid of 6 realistic student profile cards showing: Name, Branch, Year, Skills (as pills/badges), Availability ("Free for Hackathons"), and a "Connect" button.

Clicking "Connect" opens a modal showing contact info and a message input.

Working instant search/filter: typing in the search bar or clicking tags filters the cards in real time.

For the other 6 tabs, leave clean placeholder cards saying "Module coming next".
